# 삼종 명반 계산 검수 보완 — 2026-10-30

## 변경 범위
- `gukguk.ts`: 겁재 투출을 양인격으로 곧바로 매핑하지 않고 기존 양간 양인표 및 건록 월지 조건을 확인한다. 조건 불충족 시 strict 내격은 null을 반환한다.
- `latentGukguk.ts`: 같은 월지 검증을 사용한다. 정화·인월에서 본기 갑목의 정인 후보와 천간 투출에 의한 확정 격국은 구분한다.
- `timeCalculationAudit.ts`: 날짜를 포함한 분 단위 이동, 입력값 검증, 일반적인 시진 경계까지의 거리 계산을 제공한다.
- `sajuEngine.ts`: 균시차 보정으로 날짜가 바뀌면 전일/익일 날짜도 만세력 호출에 전달한다. 원본 입력은 유지하고 보정 단계·경계 경고를 추가한다.

## 보존한 동작
경도 보정 기본값 켜짐, 균시차 기본값 꺼짐, 기존 원국/오행/구조 분석 인터페이스를 유지한다. 자미두수의 기본 시각 규칙과 서양차트의 UTC 계산은 이 패치에서 변경하지 않는다. 기존 개인 데이터, 인증, DB, 운영 서버 연결도 변경하지 않는다.

## 검증 범위
격리 단위시험 38개 통과. 만세력 외부 라이브러리는 호출 관찰용 모형으로 대체했으며, 십성 계산부는 기존 코드의 순수 계산 부분을 격리했다. 이는 전체 앱 통합시험, 실서버 재배포 검증 또는 독립 천문력 대조가 아니다. TypeScript 구문 변환만 확인했으며 전체 프로젝트 타입 검사는 별도 필요하다.

## 병합·배포 전 남은 점검
- 실제 만세력 의존성과 전체 앱 빌드/기존 테스트 실행.
- LMT 내부 날짜 이월, 역사적 시간대/DST, 절기 전후, 음력 윤달, 자시 일자 규칙 대조.
- 호출부에서 새 timeAudit 필드 전달 및 화면/도구 응답 노출 확인.
- 기존 일간 제외 필터와 격국 선택 우선순위는 이번 수정 범위가 아니며 별도 검토 대상.
- ChatGPT Sites에 복사된 엔진은 이 Git 저장소 변경만으로 배포되지 않는다. 같은 소스 반영 후 실제 호출 결과로 확인해야 한다.

## 개인정보
새 시험 기록에 실제 개인의 생년월일·이름·출생지를 추가하지 않는다. 일반화한 명식 조건과 가상 달력 날짜만 사용한다.
